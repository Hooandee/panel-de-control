# Panel de Control para OpenGamepadUI

Fundación del paquete OpenGamepadUI para Panel de Control. Esta fase define únicamente el
contrato de metadatos y fixtures de lectura; no controla hardware ni publica releases.

Valida el contrato con:

```sh
python3 scripts/validate_manifest.py
```
