# Panel de Control para OpenGamepadUI

Plugin API 2.0 de Panel de Control para OpenGamepadUI. La fase 0 ofrece en Settings una vista de
solo lectura de la GPU, el TDP observado y el perfil de potencia publicados por PowerStation.
No controla hardware ni publica releases.

Ejecuta los contratos de manifiesto y empaquetado con:

```sh
python3 -m unittest discover -v -s tests -p "test_*.py"
```
