# HUD QAM UX refinement

## Objective

Make the MangoHud editor comfortable and predictable in Decky's narrow QAM panel. The interface
must remain compact, but controls must never compete for horizontal space or imply configuration
that does not exist.

## Scope

This refinement changes only the HUD frontend and opt-in presentation primitives used by it:

- HUD section spacing and card composition.
- Slider presentation inside HUD appearance and advanced settings.
- Element-row affordances, actions and focus behaviour.
- Accessible state for expandable and selectable HUD controls.
- Spanish and English copy required by the changed interactions.

The MangoHud model, RPC contract, persistence, serialization, hot reload and hardware backends do
not change.

## Layout

The HUD section is one vertical stack inside a single QAM row:

- 12 px between cards.
- 8 px between controls belonging to the same group.
- 12 px between distinct groups inside an expanded card.
- Card padding remains 12 px.

Quick presets move into the main preview/status card. Elements, Appearance, Colors and Advanced
remain separate cards. Reset remains a tertiary action at the end of the stack.

This structure must not depend on `PanelSectionRow`'s internal negative margins to create spacing.
Existing users of shared cards retain their current layout.

## Sliders

HUD sliders use a dedicated two-line composition:

1. Label on the left and formatted current value on the right.
2. A full-width native Decky slider below.

The slider has `width: 100%` and `min-width: 0`. It is not scaled with CSS transforms. The enclosing
HUD card contains Decky's focus halo without reducing the track, thumb or hit target.

Displayed values are formatted according to meaning:

- Font sizes and offsets: `px`.
- Background and text opacity: `%`.
- Font scale: `×`.
- Row spacing: signed decimal value.
- Outline thickness: decimal `px`.

## Element rows

An element is expandable only when it exposes an actual local setting:

- Blocks: submetrics, group color and supported label.
- Text: text content.
- Spacer: spacer size.
- FPS and frametime: their supported color.
- Metrics with supported labels: label field.

Separators and metrics governed entirely by global appearance are leaf rows. They have no chevron,
do not open an informational pseudo-editor, and retain only their valid move and remove actions.

Expandable rows expose their open state. Selection is never communicated only by color or chevron.

## Actions and focus

- A physical press must produce one action even if Decky emits both activation and click callbacks.
- Disabled move actions are not focus targets. Their space may be preserved for row alignment.
- The Add control remains mounted while its picker is open and changes to a Close action.
- Closing the picker returns to a valid, mounted focus target.
- Selectable pills and segmented controls expose their selected state.
- Asynchronous save/reload status remains visible and is announced without stealing focus.

## Error handling

The existing saved model remains the source of truth. Presentation changes do not introduce a
second draft or alter debounce behaviour. If an action fails, existing HUD save/reload status
continues to report the failure.

Leaf-row detection is derived from MangoHud's supported editing rules, not from whether an editor
happens to render content. Adding a future local setting therefore requires explicitly making that
row expandable.

## Validation

Automated:

- Pure tests for leaf versus expandable rows.
- Component tests for slider geometry/value formatting.
- Component tests for single activation and disabled actions.
- Existing HUD model, hook, i18n, typecheck, frontend suite and production build.
- Full backend and cross-device regression gate because the branch also contains backend HUD work.

Physical QAM:

- Narrow panel in Spanish and English.
- Touch and gamepad traversal from first to last HUD control.
- Add/open/close flow without orphaned focus.
- Every HUD slider stays inside its card at minimum and maximum values.
- Leaf rows never show a chevron; editable rows open and close consistently.
- No duplicate reload, modal or reset action from one press.

## Out of scope

- Global replacement of `ContainedSlider`, `Collapsible` or every duplicated Decky action.
- Filtering the MangoHud metric catalog by GPU, driver or gamescope capability.
- Changing the meaning of Steam's performance-overlay level.
- Backend, preset serialization or hot-reload semantics.
